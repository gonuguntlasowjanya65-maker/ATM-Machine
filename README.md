# 🏧 ATM Machine Simulation Using Python

A simple and beginner-friendly **ATM Machine Simulation** project developed using only **Python**.
This project simulates basic ATM functionalities such as checking balance, depositing money, withdrawing cash, and viewing transaction details through a command-line interface.

The project is designed to help beginners understand Python programming concepts and real-world banking operations in a simple and practical way.

---

# 📌 Features

✅ User login with PIN authentication
✅ Check account balance
✅ Deposit money
✅ Withdraw money
✅ Display transaction details
✅ Simple and interactive command-line interface
✅ Beginner-friendly Python code
